## Key Findings

1. **RMS has 0 cuts** — never truncates speech
2. **Silero cuts 59% of reps** — aggressive endpoint detection
3. **Hybrid cuts 76% of reps** — hangover doesn't prevent cuts
4. **Silero/Hybrid start 140ms earlier** than RMS (180ms vs 320ms)
5. **Silero/Hybrid endpoint at window edge** (4000-6000ms) — no real endpoint detected
6. **6/17 reps missed by all pipelines** — mic instability or low speech

## Decision

**KEEP CURRENT (Pipeline A / RMS)**

Rationale:
- RMS: 0 cuts, reliable speech detection
- Silero: 59% cuts — unacceptable for production
- Hybrid: 76% cuts — worse than Silero alone
- No latency advantage justifies cut risk
