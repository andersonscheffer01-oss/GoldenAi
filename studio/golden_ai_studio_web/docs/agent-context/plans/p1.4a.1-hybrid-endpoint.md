# P1.4A.1 — HYBRID ENDPOINTING — Execution Plan

## Context

P1.4A benchmark concluded:
- **Pipeline A (RMS)**: P50=2048ms endpoint, 0 cut words, 960ms speech start
- **Pipeline B (Silero)**: P50=1230ms endpoint, 10 cut words, 1080ms speech start

Silero is 818ms faster at endpoint but cuts trailing words. RMS preserves all words but is slower. Goal: combine both for fast endpoint + zero cuts.

---

## Architecture

### New File: `jarvis_core/realtime_voice/hybrid_endpoint.py`

Standalone module (~150 lines). Does NOT modify `vad.py`. Sits between Silero VAD and UtteranceBuffer.

**3-phase state machine:**

```
IDLE → SPEECH (on Silero SPEECH_STARTED)
SPEECH → HANGOVER (on Silero ENDPOINT → becomes END_CANDIDATE)
HANGOVER → SPEECH (RMS ≥ threshold → cancel, speech continues)
HANGOVER → IDLE (hangover expires → emit ENDPOINT)
```

**Key classes:**
- `HybridPhase(Enum)`: IDLE, SPEECH, HANGOVER
- `HybridEvent(Enum)`: SPEECH_STARTED, ENDPOINT, SPEECH_RESUMED
- `HybridEndpoint`: manages hangover state + tail frame tracking

**Methods:**
- `on_speech_started()` → phase = SPEECH
- `on_endpoint_candidate(frame)` → opens hangover, returns None or ENDPOINT
- `feed_hangover(frame, rms_energy)` → returns SPEECH_RESUMED/ENDPOINT/None
- `get_tail_frames()` / `clear_tail()` / `reset()`

**RMS energy check during hangover:** fixed threshold (300.0), not adaptive. Rationale: mid-utterance confirmation doesn't need noise floor calibration — just "any significant energy" means speech continues.

**Tail buffer:** No separate buffer. UtteranceBuffer accumulates ALL frames (SPEECH + HANGOVER). `HybridEndpoint._hangover_frames` is parallel tracking list for counting/debugging only.

### Modifications to `jarvis_core/realtime_voice/integration.py`

In `_frame_loop()` LISTENING block (~20 lines changed):

```python
# Current flow:
event = await self._vad.feed(frame)
if event == VADEvent.SPEECH_STARTED:
    self._utterance.start()
elif event == VADEvent.ENDPOINT:
    self._utterance.end()
    await self._finish_utterance()

# Hybrid flow (when JARVIS_HYBRID_ENDPOINT=1):
event = await self._vad.feed(frame)
if event == VADEvent.SPEECH_STARTED:
    self._utterance.start()
    self._hybrid.on_speech_started()
elif event == VADEvent.ENDPOINT:
    hybrid_evt = self._hybrid.on_endpoint_candidate(frame)
    if hybrid_evt == HybridEvent.ENDPOINT:
        self._utterance.end()
        await self._finish_utterance()
    # else: hangover opened, don't finalize yet

if self._utterance.active:
    self._utterance.append(frame)

if self._hybrid.in_hangover:
    energy = rms_energy(frame)
    hybrid_evt = self._hybrid.feed_hangover(frame, energy)
    if hybrid_evt == HybridEvent.ENDPOINT:
        self._utterance.end()
        await self._finish_utterance()
    elif hybrid_evt == HybridEvent.SPEECH_RESUMED:
        pass  # frames already in UtteranceBuffer
```

Non-hybrid path (`JARVIS_HYBRID_ENDPOINT=0`) is unchanged — zero regression risk.

## Approval Criteria

HYBRID wins only if:
- `cut_final_words = 0`
- End Speech P50 ≤ 1500ms (preferably 1200-1400ms)
- P95 significantly better than RMS (2048ms)
- No increase in: false endpoints, missed speech, false speech

Feature flag `JARVIS_HYBRID_ENDPOINT` stays OFF by default.
`JARVIS_REALTIME_VOICE_V2` stays OFF.
No promotion to P1.4B until explicit approval.
