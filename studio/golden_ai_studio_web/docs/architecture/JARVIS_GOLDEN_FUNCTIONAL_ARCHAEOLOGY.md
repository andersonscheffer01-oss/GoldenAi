## Findings

- The strongest recoverable value is structured read capability: scanner/radar context, market regime, risk explanation, validation status, robot/evidence provenance, and scientific memory relationships.
- The largest authority risk is not missing code; it is duplicated execution and policy paths. Legacy `/api/chat`, browser voice, direct MT5/order functions, old ToolRegistry, and auxiliary backends must not become parallel Jarvis brains.
- Existing B1 bridge work is additive and read-only. It exposes normalized overview data but does not replace full Radar UI, deep analysis, voice, or live trading.
- Raw file presence does not prove active ownership. Every recovery item requires an explicit Jarvis adapter, provenance, security decision, and freshness policy.
