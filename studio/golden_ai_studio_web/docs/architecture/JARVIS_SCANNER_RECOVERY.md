# Jarvis Scanner Recovery

GoldenScanner remains the calculation donor. B4.2 preserves its normalized
setup fields, multi-timeframe trend evidence, regime, volatility, spread,
R:R, confluence, indicators and support/resistance when available.

The canonical projection labels scores as heuristic scores, never as
probability or win confidence. Setup detection, setup quality, entry
readiness, risk acceptability and execution authorization remain separate;
the last item is not provided by this read model.

When MT5 is disabled the scanner state is `SOURCE_DISABLED`, not an empty
successful scan. The UI renders that state explicitly.
